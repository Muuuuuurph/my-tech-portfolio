# 📅 Daily Log – 2025-12-13
## Project: SIEM

### 🔧 What I worked on today
- Resolved the boot issue by installing [Raspberry Pi OS](https://www.raspberrypi.com/software/) on a [microSD card](https://www.megaknihy.cz/nezarazeno/575455-pametova-karta-maxell-microsd-16gb-ad-854717.html).
- Successfully booted the system and reconfigured the boot order to prioritize USB devices.
- Upgraded storage to a [Samsung Portable SSD T7 1TB (Black)](https://www.alza.cz/EN/samsung-portable-ssd-t7-1tb-black-d5848607.htm#fotovideo).
- Installed and configured [Wazuh](https://wazuh.com/) on the Raspberry Pi.
- Enabled the Wazuh web dashboard, turning the setup into a fully functional SIEM system.
- Integrated Wazuh with Telegram to receive security alerts and notifications in real time.

### 🧠 Notes / Learnings
- Using a microSD card is a reliable fallback for initial OS installation on Raspberry Pi.
- Changing the boot order after a successful boot allows seamless migration to USB storage.
- Wazuh provides a powerful SIEM solution even on compact hardware like Raspberry Pi.
- Telegram integration is an effective way to receive immediate security alerts.

### ❓ Blockers / Questions
- No major blockers at the moment.
- Further tuning of alert rules and dashboard visibility may be required.

### 🎯 Plans for tomorrow

- Fine-tune Wazuh rules and alert severity levels.
- Explore log ingestion from additional sources.
- Document the SIEM architecture and alerting workflow.
