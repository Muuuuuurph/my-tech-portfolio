# Cybersecurity Portfolio

Welcome to my public cybersecurity portfolio.  
This repository documents my learning journey, technical logs, security projects, and research notes. It highlights both my hands-on experience and theoretical understanding of cybersecurity.

---

## 📂 Repository Structure

- `diary/` – logs about learning, experiments, and challenges in cybersecurity.  
- `docs/` – long-term notes, decisions, and ideas about tools, techniques, and security concepts.  
- `projects/` – featured cybersecurity projects, penetration tests, CTF challenges, or lab experiments.  

---

## 🔧 Technologies & Tools

- **Languages:** Python, Bash, JavaScript (used for scripting, automation, and security tools)  
- **Tools & Platforms:** Wireshark, Burp Suite, Metasploit, Kali Linux, GitHub, FlareVM 
- **Other Skills:** network security, ethical hacking, penetration testing, cryptography, reverse engineering

1. Start with this `README.md` for an overview.
